# Jump

`jump` picks up a planned or packed dive. It reads the dive's pinned scopes, hydrates the
workspace repositories at those refs, reapplies any linked patch chains, and
leaves the work ready for the next human or agent to continue.

For each scoped work branch, it compares the pin with the fetched branch on
origin. If the branch is ahead, it warns how many commits the pin lacks; if the
branch no longer contains the pin, it warns that they have diverged. The warning
names the scope and the exact `crud <dive> --repin <branch> --scope <repo>`
command. Jump still hydrates at the recorded pin and never repins on its own.

# Dives

A dive is a small enough slice of work to enable
[TBD](https://trunkbaseddevelopment.com/). Its KB document records who's on it
right now, pinned repository scopes, progress, patches, and handoff context.

A workspace can support a single in-flight dive at a time. This encourages
agents (and humans) to pack work-in-progress before switching contexts, to make
pickup easier for the next diver.

## The record and the active marker

A dive doc's frontmatter is shaped like:

```yaml
---
kind: dive
id: <quid>
name: <slug-chain>.<quid-last-6>
gist: "<line>"
scopes:
  - <repo-ref>
meta:
  feat: <feat-path>
  diver: <person-or-agent>
---
```

The body is the dive log: progress notes, handoff notes, artifacts, warnings,
repo heads, and any context the next human or agent needs.

The active workspace focus is the dive id in
`<nosedive-workspace>/.nosedive-ref`, which contains only:

```text
id: <dive-id>
```

That marker points to one `kind: dive` doc, and that doc is the single active
dive for the workspace. Other dive records can exist for the same feat; they
are not active in this workspace unless the marker points at them.

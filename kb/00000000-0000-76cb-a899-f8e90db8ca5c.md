# Gates

A gate states what must be true before work is accepted. It is backed by an
executable check, so humans and agents can run the same proof and get an
unambiguous result instead of relying on memory or a reviewer's guess.

Gates follow the real system boundary: a gate may inspect more than one scoped
repository, and its relationship to a feat names when it runs (`land`, `test`,
or another supported phase). A red or unwritten gate keeps the work from being
reported as complete.

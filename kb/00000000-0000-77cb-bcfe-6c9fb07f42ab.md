# Dive

A dive is recorded on a feat, while another dive is active:
`nosedive crud dive --feat <feat> [--name <name>] [--title <title>] <gist...>`.
An optional brief is read from stdin; otherwise edit it on the dive's page
later. Crud hands it to `record.dive`'s own code, which defaults its name to
`<feat>.<last-6>` and its title from the feat as jump does. An explicit name
is normalized and must be unique, like any crud name. It inherits the feat's
scopes and work branches, pins each at origin's head, and links it from the
feat as `planned.dive`. A feat the backlog reaches also hands down the
backlog's scopes, so a backlog scoping the bridge lets every dive plan. It
is written in the bridge's `__self` checkout and published by land.

Recording claims nothing; `jump` does.

Its meta is nosedive's: `feat`, the `diver` and `packer` that hold it, and
`effort`, which older dives name instead of `feat`. An older dive's `root` or
`deck` is ignored. A closed dive becomes a
memo, whose meta is open.

# Repositories

A repository is one independently versioned implementation boundary. _nosedive_
records its canonical path, remotes, trunk, and conventions in a `kind: repo`
document so a feat can name the repositories it may touch.

A [dive](./00000000-0000-749c-844b-2318117bffb0.md) pins the exact repository
refs it needs (called `scopes`) and assigns the work branch that will receive
landed changes.

Upon [hydration](./c4e93002-2925-58bd-9b70-d917017a9fc7.md), a `git worktree` is
created for the repo in the workspace, checked out at the dive's pinned commit.

## Record shape

```yaml
meta:
  path: workspace/nosedive   # working checkout, relative to the bridge root.
                             # The repo's canonical nosedive target.
  url: https://github.com/org/repo
                             # optional human-facing repository page.
  trunk: main                # default branch; the detached read-only head and
                             # the base for writable sessions.
  merge: pull-request        # how landed work reaches trunk.
  remotes:
    cloud: git@github.com:org/repo.git
                             # durable upstream clone/push URL, and the
                             # preferred source for managed caches.
    local: "~/Projects/repo" # optional existing checkout, used only as a
                             # bootstrap hint, never as the hydration target.
```

Hydration creates worktrees from a nosedive-managed cache, not directly from
`meta.remotes.local`. When both remotes exist, `cloud` is authoritative for
durable fetch and push identity.

## The body

The body is the kb's clean summary of everything durable known about the repo:
what it is, how it is commonly worked on, and which kb docs matter when
touching it. Link to those docs rather than duplicating their bodies.

Do not import README contents into a repo doc. The README belongs to the
implementation repo and may use relative asset links, badges, and other
repo-local references that do not survive the move. Summarize it or point at
it.

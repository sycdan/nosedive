# Repositories

A repository is one independently versioned implementation boundary. Nosedive
records its canonical path, remotes, trunk, and conventions in a `kind: repo`
document so a feat can name the repositories it may touch.

A dive pins the exact repository refs it needs and assigns the work branch that
will receive landed changes. That makes a multi-repo change explicit without
pretending the repositories share one worktree.

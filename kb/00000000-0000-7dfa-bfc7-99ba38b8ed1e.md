# Repo

A `kind: repo` doc is a repository the bridge knows: dives scope it by its
id, and `hydrate-repo.workspace` checks it out at `meta.path`.

`url` is the one key a new repo doc must give. A doc older than this kind --
`record.repo` without a page, the bridge's own doc that `seed` writes -- may
have only `remotes`, so a doc needs one or the other. `trunk` is the branch
work lands onto, `merge` how `drop` merges it, `remotes` where it is cloned
from by role (`cloud`, `local`), and `commit-provenance` which trailers its
commits carry.

A repo doc lives only in a bridge, like a dive: `crud repo <gist>` mints one
there, or in the bridge's `__self` checkout on a dive, and never in another
repo's kb.

# Repo

A `kind: repo` doc is a repository the bridge knows: dives scope it by its
id, and `hydrate-repo.workspace` checks it out at `meta.path`, or at
`<workspace>/<name>` when `meta.path` is absent. The deprecated
`meta.worktree-path` also takes precedence over that default.

`remotes` is the one key a repo doc must give: where it is cloned from by
role, `cloud` before `local`. `url` is the repository's web page, for people,
and is never cloned from. `trunk` is the branch work lands onto, `merge` how
`drop` merges it, and `commit-provenance` which trailers its commits carry.

A repo doc minted on a dive brings the shipped
[repo-create gate](00000000-0000-7d9b-bd90-df6c304acccb.md) onto that dive:
at land it creates the repository at `remotes.local` when nothing is there,
seeded as a bridge whose own repo doc has this doc's id.

A repo doc lives only in a bridge, like a dive: `crud repo <gist>` mints one
there, or in the bridge's `__self` checkout on a dive, and never in another
repo's kb.

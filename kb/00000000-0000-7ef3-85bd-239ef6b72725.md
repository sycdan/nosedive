# QUID

Every id nosedive mints is a uuid7, which is not an opaque key. Its leading 48
bits are the UTC millisecond of minting, so an id carries its own creation
time, ids sort chronologically by string comparison, and a synthetic timestamp
can place a document deliberately rather than wherever the clock happened to
be.

Nothing in nosedive names that property today. Docs and code say "uuid", which
is true and says nothing about the part that matters. QUID is the proposed
name for it.

## Backronym

Not settled. Candidate: **Q**uantized **U**TC **I**nstant **D**escriptor.
Anything chosen has to survive being read aloud in a code review and has to
stay true of a synthetic id, where the instant is chosen rather than observed.

## Minted at epoch

This memo's own id is minted at UTC millisecond 0, which is the demonstration:
the timestamp is a choice, and the random tail is what keeps it unique. The
packaged `kind: foundation` docs use the same trick on a 1,000,000 ms ladder --
0, 1e6, 2e6, 3e6, 5e6 -- to fix their order independently of when they were
written.

## Status

Naming only. Nothing in the code or the docs uses the term yet; writing it into
`uuid7.ts`, the mint helpers, error text, the foundation docs, the README and
the command docs is the work, and it is tracked as its own feat on the bridge
that pitched it.

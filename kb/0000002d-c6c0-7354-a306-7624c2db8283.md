# Dives (retired)

Read [dive](00000000-0000-749c-844b-2318117bffb0.md) for what a dive is, and
[kb](00000000-0000-7bee-b718-0c6abe48ee4f.md) for the record shape and the
`.nosedive-ref` marker contract, both of which moved there intact.

Retired rather than deleted so links and ids still resolve; the full text is in
git history. Its kind changed from `foundation` to `memo`, which is what
actually retires it -- nothing in the code reads `deprecated-by`, so a doc left
at `kind: foundation` keeps being read in full whatever links it carries.

Its "Workflow Boundary" section is the one part that did not move. It described
`workon` and `handoff` as runbooks that nosedive tools would supply
deterministic operations for. Those operations now exist as
[jump](00000000-0000-713d-b87c-9c86d93fd66c.md),
[pack](00000000-0000-7565-a984-ad5d34a2cffa.md),
[land](00000000-0000-70db-810d-748b23bd9e7c.md) and
[bail](00000000-0000-708a-8e3a-7cf44717d66f.md), so the boundary it was drawing
is settled and the prose describing it as future work is not worth carrying.

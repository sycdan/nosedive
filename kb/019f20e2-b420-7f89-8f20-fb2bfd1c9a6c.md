# Level 0

The first shape nosedive had.

Configuration was a single legacy `.nosediverc` at the bridge root. Work was a
directory tree of markdown files under `backlog/`, or under `efforts/` when
`backlog/` was absent, and the nesting was the only thing carrying a
parent/child relationship. There was no kb, so there were no ids -- a document
was whatever path it sat at.

Path-as-identity is what broke it. Renaming or re-parenting a document broke
every reference to it, and one flat config file left nosedive nowhere to keep
state it owns apart from state the pilot owns. Both are fixed at
[level-1](019fbba2-74f0-709d-8b0d-6ab74ee86893.md).

## Migration

None. Level 0 is the floor -- a bridge cannot arrive here from anywhere.

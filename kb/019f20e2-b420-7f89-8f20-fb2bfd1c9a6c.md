# Level 0

Minted `2026-07-01T23:32:36-04:00` (`ce44104`, the initial commit).

## What it was

- Configuration lived in a single legacy `.nosediverc` at the bridge root.
- Work was tracked as a directory tree of markdown files under `backlog/`, or
  under `efforts/` when `backlog/` was absent. Nesting carried the parent/child
  relationship; there were no `links:`.
- There was no kb, so there were no ids: a document was identified by its path.

## Why it broke

Path-as-identity meant renaming or re-parenting a document broke every
reference to it, and a single flat config file gave nosedive nowhere to keep
state it owns separately from state the pilot owns. Both are fixed at
[level-1](019fbba2-74f0-709d-8b0d-6ab74ee86893.md).

## Migration

None. Level 0 is the floor -- a bridge cannot arrive here from anywhere.

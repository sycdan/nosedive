# uuid

Wherever nosedive needs a uuid — kb filenames, session/artifact ids — it is a
**UUID version 7**: time-ordered, so a plain sort or directory listing roughly
follows creation order.

## Generate with a tool

Never hand-roll a uuid (no hand-assembled bytes, no ad-hoc scripts). Mint one
with a tool:

```sh
npx uuidv7
```

## Always generate; only reuse deliberately

Default to a **fresh** uuid every time you need one. Reuse an existing uuid
only when you are deliberately referring to the thing it already identifies
(e.g. an artifact naming itself after the session that produced it). If you are
naming something new, generate.

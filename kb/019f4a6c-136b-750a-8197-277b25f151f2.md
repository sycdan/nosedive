# Dump current backlog

Print a concise, scannable view of every effort under `efforts/`, so a
developer or agent can load "what's in flight" in one command without opening
files. Presence under `efforts/` *is* openness — finished work leaves `efforts/`
and lands in `kb/` (new knowledge or an updated state), so there is nothing to
filter out.

Read-only: it never generates or edits anything.

## Usage

```
nosedive dump-backlog
```

No arguments. Reads `efforts/` relative to the current working directory.

## Output

A tree by directory nesting. Each effort renders as a header line (`status` +
[slug chain](019f39dc-8ebf-7735-812d-522cc242a8b8.md), indented by depth) and an
indented gist line:

```
planned      installable-skills
             Make nosedive a distribution vehicle for agent skills
  planned    installable-skills.install-skill
             Add `nosedive install-skill` to the CLI
in-progress  kb-store
             Define kb/ as nosedive's knowledge base
```

The gist is derived from the first paragraph of each effort's `## Goal` section
(efforts carry no `gist:` frontmatter), collapsed to one line and truncated.

## Behavior

1. Resolve `efforts/` under the cwd. If absent, print a friendly "no open
   efforts" line and exit 0.
2. Walk recursively; each effort folder holds one `<EffortName>.md`.
3. Parse frontmatter (`slug`, `parent`, `status`).
4. Render every effort as the tree above, parent before child.

## Exit codes

- `0` — printed successfully, including the empty-backlog case.

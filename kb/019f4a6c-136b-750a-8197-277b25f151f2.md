# Dump current backlog

Print a concise, scannable view of every [open
effort](./00000000-0000-0000-0000-000000000001.md#lifecycle), so a developer or
agent can load "what's in flight" in one command without opening files.

Read-only: it never generates or edits anything.

## Usage

```
nosedive dump-backlog
```

No arguments. Reads `efforts/` relative to the current working directory.

## Output

A tree by directory nesting. Each effort renders as a header line (`phase` +
[slug chain](./019f39dc-8ebf-7735-812d-522cc242a8b8.md#why-leaf-first), indented by depth) and an
indented gist line:

```
framing    installable-skills
           Make nosedive a distribution vehicle for agent skills
  shaping  install-skill.installable-skills
           Add `nosedive install-skill` to the CLI
building   kb-store
           Define kb/ as nosedive's knowledge base
```

The gist comes from each effort's `gist:` frontmatter, truncated to fit.

## Behavior

1. Resolve `efforts/` under the cwd. If absent, print a friendly "no open
   efforts" line and exit 0.
2. Walk recursively; each effort folder holds one `<EffortName>.md`. The slug
   is the folder name.
3. Parse frontmatter.
4. Render every effort as the tree above, parent before child.

## Exit codes

- `0` — printed successfully, including the empty-backlog case.

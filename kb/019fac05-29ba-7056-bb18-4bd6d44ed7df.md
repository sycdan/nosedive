# Whoami

Queries `git config` for developer name and email, and outputs them in a specific format:

```text
nosedive-pilot-name: <git-config-name>
nosedive-pilot-email: <git-config-email>
```

This allows `nosedive` to reliably use tokens like `nosedive-pilot-name` to drive logic in agent instructions.

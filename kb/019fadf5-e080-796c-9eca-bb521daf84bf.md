# Mint

Generates UUIDv7 values with a chosen timestamp encoded in the high bits, so
minted ids sort in the order they were meant to represent rather than the
order they happened to be created.

- `[timestamp]` accepts an ISO date string or Unix milliseconds, and defaults
  to now.
- `[count]` defaults to `1`. Each additional id advances the encoded timestamp
  by one millisecond, so a batch sorts lexicographically.
- The timestamp must fall inside the 48-bit UUIDv7 range.

Example:

`npx -y nosedive@dev mint 1997-08-29T02:14:00-04:00`

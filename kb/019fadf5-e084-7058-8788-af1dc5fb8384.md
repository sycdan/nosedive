Usage: nosedive init [--headless]
  Deprecated: use `nosedive seed` instead.
  Create, migrate, or edit bridge config (.nosedive/config.yaml + .nosedive.local.yaml) in the current directory.
  Existing values (or built-in defaults) are shown as the default for each prompt; press Enter to keep it.
  --headless skips prompts and writes existing values or configured defaults.
  Every run first migrates an out-of-date bridge config to the latest compatibility level (a no-op when already current).

# Init

Deprecated alias for [`seed`](019fadf5-e082-7558-945f-d136295b1ea5.md).

Prints `warning: `nosedive init` is deprecated; use `nosedive seed` instead.`
on stderr, then runs the same setup and migration path as `seed`. Behavior is
otherwise identical, including `--headless`.

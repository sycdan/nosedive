# Init

Deprecated alias for [`seed`](019fadf5-e082-7558-945f-d136295b1ea5.md).

Prints `warning: `nosedive init` is deprecated; use `nosedive seed` instead.`
on stderr, then runs the same setup and migration path as
[`seed`](019fadf5-e082-7558-945f-d136295b1ea5.md). Behavior is otherwise
identical, including `--headless`.

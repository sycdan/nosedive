# Pitch

`<slug>` is the effort directory name in kebab-case. The effort file inside it
is the slug in PascalCase, so slug `foo-bar` lands at
`backlog/foo-bar/FooBar.md`.

`--parent` can be an effort path, a domain directory path such as
`backlog/gogglebox`, or a leaf-first slug chain such as `baz-qux.foo-bar`.
Subefforts are nested directories, so a parented pitch lands at
`backlog/foo-bar/baz-qux/BazQux.md`.

`--gist` and `--pitch` seed the new effort's frontmatter gist and its framing
section.

Pitch writes the new effort file locally, and fails if the target effort
directory already exists.

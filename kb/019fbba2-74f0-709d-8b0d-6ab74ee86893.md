# Level 1

Identity and ownership. Every document gets an id that outlives its path, and
nosedive gets its own directory to keep state in.

`.nosediverc` is replaced by a checked-in `.nosedive/config.yaml`, alongside a
`.nosedive/` directory nosedive owns for its own local state -- git cache,
migration backups -- and gitignores. `backlog:` stops naming a directory and
starts naming a kb memo by id. Legacy effort files are copied into `kb/` as
documents with minted ids, and the nesting that used to live in the directory
tree is rewritten as durable `rel: parent` and `rel: child` links. A
`kind: repo` doc for the bridge itself is minted if no existing one matches a
remote.

## What else shipped at this level

The dive loop was built here. `record.dive`, `pack` and `jump` arrived together,
and the handoff between them became something an agent can act on: `jump` briefs
the runner from the dive's own brief, and the run ends at committed work rather
than a dirty worktree. `seed` started rendering an agent-facing command surface
into the instructions file the bridge already carried, with `scan` and `spin`
alongside it as documentation-only briefings. `drop` arrived at the end, gated
on a release date.

The guardrails came with it: `land` verifies a scoped repo before it pushes,
every commit nosedive authors carries its own provenance, and `meta.diver`
became the one thing that says whether a dive is held.

## Migration

[`seed-L1-bridge`](019f916b-f800-723d-b096-07d4300ff28a.md) -- **live**. An L0
bridge's data is unreadable at L1 until it runs, so every contracted command
refuses on an L0 bridge until `nosedive seed` has migrated it.

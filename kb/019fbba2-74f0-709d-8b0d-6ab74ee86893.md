# Level 1

Minted `2026-08-01T00:43:34-04:00` (`e5bf413`, which adds `seed-L1-bridge`).

That commit is the earliest evidence that level 0 was declared broken: it lands
10 hours before the first `@1` command docs (`cbeb209`) and 11 hours before
`CURRENT_COMPATIBILITY_LEVEL = 1` (`e7736cb`). The break is dated from the
moment the migration was written, not from the moment the constant moved.

## What changed

- Config splits: `.nosediverc` is replaced by a checked-in
  `.nosedive/config.yaml`, alongside a `.nosedive/` directory nosedive owns for
  its own local state (git cache, migration backups) and gitignores.
- `backlog:` stops naming a directory and starts naming a kb memo by id.
- Legacy effort files are copied into `kb/` as documents with minted UUIDv7
  ids, their nesting rewritten as durable `rel: parent` / `rel: child` links.
- A `kind: repo` doc for the bridge itself is minted if none matches a remote.

## Migration

[`seed-L1-bridge`](019f916b-f800-723d-b096-07d4300ff28a.md) -- **live**. An L0
bridge's data is unreadable at L1 until it runs, so every contracted command
refuses on an L0 bridge until `nosedive seed` has migrated it.

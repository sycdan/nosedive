# Nosedive Workspace

`<nosedive-workspace>` means the workspace root configured by `workspace:` in
the bridge's `.nosedive/config.yaml`, interpreted relative to the `<nosedive-bridge>`.
It is a documentation placeholder, not a literal directory name or shell
variable. Resolve it from bridge config before running a command that needs a
concrete path. It should always be rendered as a POSIX path, even on Windows hosts.

# Seed L2 Feats (retired)

This migration no longer runs and has no script. It is kept because its "Why"
is [level 2](019fda55-7348-7568-825c-d039467180d6.md)'s release note, and that
is the provenance worth keeping.

## Why

Effort acquired a second meaning. A command doc declares a `minimum-effort` and
`maximum-effort`, and the bridge maps each effort number to a model in
`agent-effort-<n>`, so "effort" now names how hard nosedive is allowed to try.
Using the same word for the unit of work made every sentence about either one
ambiguous -- "the effort's scopes" and "the effort's model" are not the same
kind of thing, and no reader could tell which was meant without context.

The unit of work becomes `kind: feat`. Effort keeps the meaning it earned.

## Why it was retired

Kind stopped being load-bearing: readers accept any kind and reject on rel role
and document shape instead. A document still saying `kind: effort` reads exactly
as well as one saying `kind: feat`, so there was nothing left for the migration
to fix -- and a migration that must run to reach a level makes that level
expensive for no gain.

The script was also carrying a latent bug, which is the reason it should not
have survived even unretired: it hardcoded `join(bridgeDir, "kb")` and ignored
the configured `kb:` path. A bridge with its kb elsewhere got `featCount: 0`, a
config bumped to 2 anyway, and every document left unmigrated.

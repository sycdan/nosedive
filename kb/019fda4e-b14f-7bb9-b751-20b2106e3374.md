# Seed L2 Feats

This migration runs when a bridge crosses from L1 to L2.

## Why

Effort acquired a second meaning. A command doc declares a `minimum-effort` and
`maximum-effort`, and the bridge maps each effort number to a model in
`agent-effort-<n>`, so "effort" now names how hard nosedive is allowed to try.
Using the same word for the unit of work made every sentence about either one
ambiguous -- "the effort's scopes" and "the effort's model" are not the same
kind of thing, and no reader could tell which was meant without context.

The unit of work becomes `kind: feat`. Effort keeps the meaning it earned.

## What it migrates

Kind stopped being the backlog selector. A document still saying `kind: effort`
can be backlog work if the backlog tree points at it with a `.feat` role, while
a managed doc such as a repo or dive must never become backlog work merely
because the body linked it.

The L1 backlog memo body already carries the pilot-visible tree. This migration
parses that rendered body, resolves its markdown links against the configured
`kb:` directory, and rewrites only the relevant `links:` frontmatter:

- backlog memo links to root body entries gain the `.feat` role suffix, so
  `rel: release` becomes `rel: release.feat`. `rel: main-effort` is what the
  L0 seed wrote for every root, a machine default rather than a filing, so it
  becomes `rel: current.feat` and renders under `## Current`;
- parent work docs link to body children with `rel: child.feat`;
- child work docs link to their body parent with `rel: parent.feat`;
- stale parent/child effort rels between body-listed work docs are removed.

Bodies, scopes, names, gists, kinds, metadata, and unrelated links are
preserved.

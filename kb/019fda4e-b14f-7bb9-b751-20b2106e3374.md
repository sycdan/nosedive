# Seed L2 Feats

`nosedive seed` rewrites every bridge KB document whose frontmatter says
`kind: effort` to `kind: feat`, then reports how many documents changed.

## Why

Effort acquired a second meaning. A command doc declares a `minimum-effort` and
`maximum-effort`, and the bridge maps each effort number to a model in
`agent-effort-<n>`, so "effort" now names how hard nosedive is allowed to try.
Using the same word for the unit of work made every sentence about either one
ambiguous -- "the effort's scopes" and "the effort's model" are not the same
kind of thing, and no reader could tell which was meant without context.

The unit of work becomes `kind: feat`. Effort keeps the meaning it earned.

## What It Touches

Only the frontmatter block of each doc. A body may legitimately hold the line
`kind: effort` -- a doc explaining the kind, a fenced example of a doc's shape
-- and a migration that rewrites prose it was never asked about is one nobody
can safely re-run.

Commands whose contract reads the kind are republished at `@2`; commands that
never read it stay at `@1` and are unaffected by this migration.

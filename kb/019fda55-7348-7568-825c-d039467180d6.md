# Level 2

Minted `2026-08-06T23:47:41-04:00` (`6618291`, "Generalize prompt execution and
migrate feats").

That one commit carried `seed-L2-feats`, the `CURRENT_COMPATIBILITY_LEVEL` bump,
and `drop@2` -- the first `@2` command doc, five hours before the bulk
(`b061134`). Mint and release collapsed into a single instant, which is exactly
what this model separates going forward: a level is minted the moment something
breaks the previous one, accrues notes while it is unreleased, and ships later.
Level 2 is the last level for which that distinction is unrecoverable.

## What changed

The unit of work is `kind: feat`, not `kind: effort`.

Effort had acquired a second meaning. A command doc declares a
`minimum-effort` and a `maximum-effort`, and the bridge maps each effort number
to a model in `agent-effort-<n>`, so "effort" also names how hard nosedive is
allowed to try. "The effort's scopes" and "the effort's model" were not the same
kind of thing, and no reader could tell which was meant without context.

Commands that read the kind were republished at `@2`; commands that never read
it stayed at `@1`.

## Migration

[`seed-L2-feats`](019fda4e-b14f-7bb9-b751-20b2106e3374.md) -- **retired**, and
kept only as this level's provenance.

The migration rewrote frontmatter in every bridge document. It was retired once
kind stopped being load-bearing: readers accept any kind and reject on rel role
and document shape instead, so a document still saying `kind: effort` is read
exactly as well as one saying `kind: feat`. Nothing needs rewriting, so a bridge
at level 1 now reaches level 2 with nothing to run and no kb writes at all --
only the one-line `compatibility-level:` diff the next `nosedive seed` makes.

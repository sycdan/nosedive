# Level 2

The unit of work is `kind: feat`.

It used to be `kind: effort`, and effort had quietly acquired a second meaning.
A command doc declares a `minimum-effort` and a `maximum-effort`, and the bridge
maps each effort number to a model, so "effort" also named how hard nosedive is
allowed to try. "The effort's scopes" and "the effort's model" were not the same
kind of thing, and no reader could tell which was meant without being told.

`feat` is what `pitch` mints, and it is what the backlog tree, `drop`, and
`pitch`'s own name-clash check select on. Kind may filter. What kind may not do
is reject: no reader refuses a document because of the kind it carries. So a
document still saying `kind: effort` is read normally everywhere kind is not the
selector, and simply does not appear in the places where it is.

Fourteen commands carry an `@2` doc: `add-repo.effort`, `bail`, `drop`,
`dump-backlog`, `into`, `jump`, `land`, `list-dives`, `pack`, `pitch`,
`preflight`, `record.dive`, `spin` and `update-backlog`. A command doc's level
says which bridge it can read, not when it was written -- so `test`, which is
new at this level, is documented at `@1`, because it does not read the unit of
work either.

## What else shipped at this level

The rename is the compatibility break. It is not most of what changed.

**A dive can be checked before it lands.** `test` runs the gates a dive claims
through `rel: land.gate`, or one named gate, or -- with `--full` -- exactly the
set `land` would run, so a clean run is a truthful preview of a land rather than
a similar one. A dive that links no gates is reported rather than called green,
and a missing shell no longer poses as a test failure. Command and gate output
streams as it is produced instead of arriving once the run is over.

**`drop` became the verb that ships a feat.** It prints the configured drop
prompt followed by generated repo, branch, gate and close-out context, hands
that to an agent, and escalates through effort tiers when a run fails. Readiness
blockers are all reported at once, on stderr, rather than one per attempt.

**`bail` became a record rather than a discard.** It requires a `--reason` and
refuses without one, writes down every commit it abandons before abandoning it,
and returns each scoped worktree to its repo trunk.

**Worktrees survive the commands that used to remove them.** `land` and `pack`
leave each scoped worktree hydrated where it belongs instead of force-removing
it, which keeps the repo visible to an editor's git tracker, makes a re-jump
cheap, and stops a locked file from leaving a half-removed checkout behind.
Hydrated worktrees are push-isolated, so only `land` can reach an implementation
remote.

**Agents got somewhere to write.** `jump` gives each dive a scratch directory
inside the workspace and names it in the handoff, so a runner that needs to
stage a file stops inventing `/tmp` and getting refused by its own sandbox.

**Explanations became documents.** A refusal resolves its prose from a kb doc
rather than carrying it in code, and a compatibility level is declared by a
`kind: level` doc -- this one -- with the README's release-notes section
generated from the set of them.

## Migration

[`seed-L2-feats`](019fda4e-b14f-7bb9-b751-20b2106e3374.md) -- **retired**, and
kept only as this level's provenance.

It rewrote frontmatter in every bridge document. It is no longer needed because
the level-1 migration writes `kind: feat` directly, so a bridge cannot arrive at
level 2 still carrying the old kind. Nothing is left to rewrite: an L1 bridge
reaches L2 with nothing to run and no kb writes at all -- only the one-line
`compatibility-level:` diff the next `nosedive seed` makes.

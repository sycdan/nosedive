# Dive Scratch Space

This is a workspace-local temporary space that agents can use instead of
`/tmp`. It allows them to write command output to a place where they do not
need special permission, reducing headless agent failures.

- `jump` recreates it, clearing old contents.
- `pack` leaves it alone and does not capture it.
- `land` and `bail` remove it.
- `nuke --workspace` removes it.

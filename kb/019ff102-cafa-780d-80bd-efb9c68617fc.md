# Level 3

Level 3 replaces the single backlog with an ordered set of decks. New feats
enter on the highest deck. Each `nosedive drop` moves a ready feat to the next
lower deck, and dropping a fully landed feat from the lowest deck removes it
from the board.

The deck names and their readiness rules are still to be designed; this is the
release boundary that will make that workflow possible.

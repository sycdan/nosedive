# How do I change what Nosedive adds to commit messages?

Nosedive adds `Nosedive-Dive:`, `Nosedive-Feat:`, and `Co-Authored-By: nosedive
...` trailers to commits made in a hydrated workspace repository by default. To
change this, configure any repository's `kind: repo` KB document like this:

```yaml
meta:
  commit-provenance:
    dive: false
    feat: false
    co-author: false
    signoff: true
```

Set `dive`, `feat`, or `co-author` to `false` to suppress just that trailer.
`commit-provenance.effort: false` remains a supported older spelling for
`feat: false`. Set `signoff` to `true` to add `Signed-off-by: <name> <email>`
from the bridge pilot's Git identity; it is off by default.

Run `nosedive jump` again after changing the repo document so it reconciles the
workspace hook. Future commits in that hydrated repository use the selected
trailers.

This setting applies only to commits made in that workspace repository. It does
not change Nosedive's bridge bookkeeping commits, which continue to carry the
co-author trailer.

# How do I stop Nosedive adding a co-author trailer?

Nosedive adds a `Co-Authored-By: nosedive ...` trailer to commits made in a
hydrated workspace repository by default. To suppress that trailer for one
repository, add this metadata to that repository's `kind: repo` KB document:

```yaml
meta:
  commit-provenance:
    co-author: false
```

Run `nosedive jump` again after changing the repo document so it reconciles the
workspace hook. Future commits in that hydrated repository then keep their
`Feat:` trailer but omit Nosedive's `Co-Authored-By` trailer.

This setting applies only to commits made in that workspace repository. It does
not change Nosedive's bridge bookkeeping commits, which continue to carry the
co-author trailer.

# Pack

Requires an active dive marker at `<workspace>/.nosedive-ref`. For every repo
scoped on that dive:

- A writable scope is captured: one binary-safe patch artifact per commit
  ahead of the scope's pinned `ref` (`git format-patch`, preserving the
  original sha and subject), then one final patch for any remaining
  staged/unstaged/untracked changes (`git diff --binary HEAD`, untracked files
  folded in via intent-to-add).
- A read-only scope is never packed. If it carries any commits ahead of its
  pin or any dirty state, `pack` refuses rather than discard it silently;
  re-scope it writable or dehydrate it by hand first.

Any other dirty file under the bridge's `kb/` directory (besides the dive
doc itself and the artifacts just written) is captured the same way, as one
combined patch.

Links are for docs, so no `.patch` file is ever linked directly. Each captured
patch is wrapped in its own `kind: memo`: `gist` is the commit's first line
(or a synthetic one for dirty/bridge-wip state), the body is the rest of the
message, `meta.patch` names the `.patch` file, and the memo links the *next*
memo in reapply order with `rel: next` -- chaining oldest commit first,
dirty state last. The dive doc links only the head of each chain, `rel:
patch`; walking `next` from there is the deterministic reapply order, not the
position of a link in a YAML array.

## Commit and push

Only the dive doc and the new artifact files are staged. Anything else dirty
in the bridge is stashed first (`git stash push --keep-index`) so the commit
and the fast-forward pull that precedes it see a clean tree, then popped back
after the push. The commit message is `pack(<dive-name>): packed <n>
artifact(s)` when the run captured artifacts, or `pack(<dive-name>): put down`
when it only released the dive. The bridge must have an upstream to push to;
pack refuses otherwise. A failed fast-forward pull or push fails loud -- the
dive is left committed locally.

## After the push

No worktree is removed. Once the bridge push (or the no-op case, when there was
nothing to pack) completes, every scoped repo -- writable and read-only alike --
is left hydrated where it stands, detached at the commit whose work was just
captured, with its `.nosedive-ref` marker intact. Clearing a checkout is a
separate, deliberate act: `dehydrate-repo.workspace --force` or
`nuke --workspace`.

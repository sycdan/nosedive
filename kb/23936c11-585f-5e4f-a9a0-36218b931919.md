# Run Gate

Runs exactly one gate document by UUID. The document must have a gate kind and a bridge-relative `meta.test-script` exporting `run(ctx)`. Hydrated workspace repositories are provided through `ctx.repos`; an active dive id is provided when one is open. The gate's stdout and stderr are forwarded, and this command exits with the gate's status.

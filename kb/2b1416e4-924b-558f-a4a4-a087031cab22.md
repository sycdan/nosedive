# Add repo to feat

Resolves `<repo-id-or-name>` against bridge KB `kind: repo` docs by `id` or
exact `name`, then appends that repo id to the active `kind: feat` doc's
`scopes:` list.

The active feat is read from local `current.feat`, or from the active dive
marker when a dive is selected. `current.feat` may be a feat doc UUID,
bridge-root KB path such as `kb/<id>.md`, or exact feat `name`.

- `--ref` pins the feat scope to a ref. When omitted, the scope has no `ref`
  key and downstream scope resolution falls back to the repo's configured trunk.
- `--read-only` records the feat scope with `mode: ro`; otherwise the command
  records `mode: rw`.

# Prove Host

Private command used by [`prove`](2cc76d81-d0de-58a1-87a2-3e4a4acaa624.md) to
run a prover artifact in an isolated child process.

It accepts exactly one argument: the path to a JSON request file written by the
parent `prove` command. The request names the bridge, assertion, prover
artifact, result path, and verbosity flag. The host imports the prover, runs
`prove(ctx)`, writes the structured result file, and exits with the prover
status.

The leading underscore marks this as private package plumbing: it is runnable,
but hidden from public command indexes.

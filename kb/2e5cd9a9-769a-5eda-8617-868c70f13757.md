# Find

Walk the graph reachable from the configured backlog and select link targets
whose relation ends in the requested role. The backlog's scoped repos are
walked too, so the notes and gates a repo carries are reachable. Duplicate
targets print once. With a term, keep documents whose name or slugified gist
contains the slugified term. Matches render as backlog entries do: a markdown
link titled by the document's H1, or by its name where it has none.

`--scope <repo>` takes a repo name or id, may be repeated, and keeps a document
that scopes any of the named repos. It also limits which repos are walked.

`--min-age` and `--max-age` accept `m`, `h`, `d`, or `w` units such as `5m`,
`2h`, `7d`, or `1w`, and must describe a window: a `--min-age` at or beyond
`--max-age` is refused. Age comes from the first Git commit that added the
document path; a document Git has never seen counts as brand new. With neither
flag, `find` shows the past week.

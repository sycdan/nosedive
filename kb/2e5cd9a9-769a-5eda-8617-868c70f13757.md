# Find

Walk the graph reachable from the configured backlog and select link targets
whose relation ends in the requested role. Duplicate targets print once. With a
term, return only documents whose slugified gist or already-slugified document
name exactly matches it.

`--age <duration>` accepts `m`, `h`, or `d` units such as `5m`, `2h`, or `7d`.
Age is based on the first Git commit that added the document path, and a
document must be at least that old to match.

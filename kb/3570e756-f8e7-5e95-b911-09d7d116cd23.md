# Nuke

Destructive, so it fails unless `--config` or `--workspace` is provided.

With `--config`, removes `.nosediverc`, `.nosedive/config.yaml`,
`.nosedive.local.yaml`, and `.nosedive/.gitignore` when present, and reports
how many files it removed.

Also removes nosedive-managed config exclude blocks from Git's local
`.git/info/exclude`, including the older package-foundation exclude block.

With `--workspace`, scans the configured workspace's direct child directories
for nosedive-managed repo markers, force-removes those Git worktrees, verifies
their source repos no longer register a worktree at that path, and removes
`<nosedive-workspace>/.nosedive-ref`. After managed worktrees are deregistered, any
remaining workspace entries are removed so the workspace is left empty.

Bridge kb and backlog contents are left alone.

# Make

`make <thing> <name...>` makes one thing in the bridge and commits it. The
name is every word after the thing, joined by spaces, so it needs no quotes.
`deck` is the only thing it makes so far.

## make deck

The name is slugged into the deck's tag -- `Magic: The Gathering` becomes
`magic-the-gathering` -- and the deck doc is written at the tag's
deterministic id: the uuid5 of the bridge's repo id (the config's `bridge:`)
and the tag. Its title is the name as typed.

The tag joins the bridge config's `decks:` unless it is listed there already,
in which case the doc is what was missing. With no `decks:` yet, the backlog
memo is written in first, because an absent `decks:` means the backlog is the
one deck, and adding a deck must not hide it. `decks:` is always written as a
comma string: `seed` carries forward only the config keys it does not own
that are scalars.

The doc and the config are one pathspec commit, `deck(<tag>): created`, and
nothing is pushed. A deck whose doc already exists is refused, as is a name
that slugs to nothing.

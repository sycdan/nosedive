# Into

Deprecated compatibility route for [`plan`](162068fe-62ff-5f56-945a-76b24ffeb439.md).
It emits a warning and then prints the same planning prompt.

The alias retains `--exec`, context handling, and active-dive guards so existing
callers fail or succeed exactly where `plan` does. New callers should use
`plan`; no planning behavior is independently maintained here.

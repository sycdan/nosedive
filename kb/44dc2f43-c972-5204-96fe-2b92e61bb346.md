# Spin

`spin <loads>` requires words describing the loads the pilot needs and an active
dive. It walks the active dive feat's ancestry, gathers each scoped repo's
linked `kind: load` documents, and prints their names and gists for a runner to
choose from. It does not select or run loads.

Repos with no linked loads are reported alongside the `scan --repo <ref>`
command that would document any. A repo may legitimately have none -- a library
or a CLI has nothing runnable -- so this is a note, not a defect.

# Record repo

Registers one Git repository as a `kind: repo` document and adds its id to the
configured backlog memo's `scopes:`. Backlog scopes are the bridge's repository
registry: a registered repository stays visible even when no open feat uses it.

The positional argument accepts a clone URL or a local Git repository path. A
local repository is recorded as `meta.remotes.local`; when it has a URL-shaped
`origin`, that is also recorded as `meta.remotes.cloud`. A clone URL is
validated with Git before anything is written.

The name defaults to a kebab-case form of the repository directory or clone URL
leaf. `--name` overrides it and must be kebab-case. Duplicate names and duplicate
remote identities are refused so repository lookup stays unambiguous.

The base branch is inferred from the remote HEAD, `origin/HEAD`, or the local
repository's symbolic HEAD, in that order where each is available.
`--base-branch` supplies it when the repository cannot advertise one or when the
pilot wants a different trunk.

The hydrated workspace path is `<configured-workspace>/<name>`. The command
only records metadata; `hydrate-repo.workspace`, `jump`, or another command
that needs the repository hydrates it later.

# Spin

`spin <loads>` requires words describing the loads the pilot needs and an active
dive. It walks the active dive effort's ancestry, gathers each scoped repo's
linked `kind: load` documents, and prints their names and gists for a runner to
choose from. It does not select or run loads.

Repos with no linked loads are reported with the `scan --repo <ref>` command
needed to document their workloads.

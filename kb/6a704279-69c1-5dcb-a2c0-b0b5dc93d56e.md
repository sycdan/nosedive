# Helm

Helm is a separate product. `nosedive helm` launches it, passing every
argument through, with its output on this terminal and its exit code as this
command's.

The helm it runs is `NOSEDIVE_HELM`, a path, when that is set, else
`nosedive-helm` on PATH. A path ending `.js`, `.mjs` or `.cjs` runs under this
node. With no helm installed it says so and exits 1.

Helm runs against this install, which it is told about through three
variables:

- `NOSEDIVE_CORE`: this package's root; helm imports `dist/nosedive.js` from
  it, the core API marked as helm's in `src/nosedive.ts`.
- `NOSEDIVE_CLI`: this package's `dist/cli.js`; helm runs it for every write,
  so its changes are nosedive's own commands.
- `NOSEDIVE_PROTOCOL`: the version of that core API (`HELM_PROTOCOL`). A helm
  built for another version refuses to start and names which side to update.

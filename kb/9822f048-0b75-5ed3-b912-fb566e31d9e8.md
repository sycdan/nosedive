# Record dive

Without `--ref`, records a new dive and requires `--effort`. New dives use a
managed `<effort-name>.<uuid-last-6>` name and default their gist to `Working on
<EffortTitle>.`.

`--ref` patches an existing `kind: dive` document. It accepts a same-bridge
document UUID, bridge-relative KB path, `.nosedive-ref` path, or a directory
containing that marker. Omitted fields remain unchanged.

`--brief` writes a `## Brief` section, on create or on `--ref`, and refuses
when the dive already has one: the brief is what informed everything already
built on that dive, so replacing it would make the record lie. A brief that
turned out wrong is a reason to `bail` and pitch a fresh dive, not to edit.

It is written for the agent that will work the dive, not as a readback of the
pilot's ask -- one small slice, where the code is now, and what has to be true
for the dive to be done.

`--title` replaces the document H1. Explicit scopes
replace all scopes and pin the latest cached trunk commit; omitted scopes keep
existing scopes on update and discover managed workspace repos on create.
`--clear-scopes` writes an empty scope list and cannot be combined with
`--scope`.

When `--diver` equals the configured Git pilot email, the updated dive becomes
the active workspace dive if no different active dive exists.

`--diver` claims a dive nobody holds. It refuses to reassign a dive that
another diver already holds, because that pilot may be working it right now.

`--takeover` is how a held dive changes hands: it reads the current holder off
the dive, writes the configured Git pilot email in their place, and refuses
when the dive is not held at all. It takes no value and cannot be combined
with `--diver`, so a takeover can only ever assign the dive to the pilot
running it, and lands as its own commit -- the takeover is on the record.

`pack` is what frees a dive without reassigning it: it clears the diver, so a
packed dive is claimable again.

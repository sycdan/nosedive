# Render

Reads `kb/<uuid>.md` from the installed nosedive package, not from the bridge
kb. By default prints only the markdown body; YAML frontmatter is stripped.
With `--gist`, prints only the doc's `gist` frontmatter field instead -- an
error if the doc has none.

Used by agents, hooks, and error messages to point at package-owned docs without
copying them into a bridge. Because it reads package files rather than bridge
files, it works outside a bridge. Commands may throw the UUID of a `kind: memo`
doc; the CLI prints that doc's gist as `nosedive-error: <gist>` and follows it
with the invocation needed to render the full doc. `--gist` reprints exactly the
short message without the fuller body.

Exactly one uuid is required. A missing or non-file target is an error.

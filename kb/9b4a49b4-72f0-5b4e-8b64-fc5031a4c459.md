# Render

Reads `kb/<uuid>.md` from the installed nosedive package, not from the bridge
kb, and prints only the markdown body; YAML frontmatter is stripped.

Used by agents and hook messages to point at package-owned runbooks without
copying them into a bridge. Because it reads package files rather than bridge
files, it works outside a bridge.

Exactly one uuid is required. A missing or non-file target is an error.

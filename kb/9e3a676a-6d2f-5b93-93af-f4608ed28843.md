# Pre-push hook

The workspace should never be checked in to the bridge's trunk, as it holds feat-specific work and tracks a single [dive](9822f048-0b75-5ed3-b912-fb566e31d9e8.md).

`git push --no-verify` bypass remains available.

## Workspace check

It reads the `workspace:` path from `.nosedive/config.yaml`, resolves that path
relative to the bridge, and compares it with paths changed by pushed commits.

- A pushed commit changing the workspace path or anything beneath it blocks.
- Commits changing only paths outside the workspace pass.
- Deleting a remote ref introduces no commits and passes.
- An unreadable config, malformed ref update, or failed Git inspection blocks.

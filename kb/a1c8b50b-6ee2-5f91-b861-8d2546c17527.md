# Dump backlog

Superseded by [`dump-backlog@1`](d90673eb-a8c6-537f-8c6c-3c38ddd13cc1.md).

Walks the configured `backlog:` directory and prints the effort tree.

Each effort directory is rendered by its slug. A directory with a matching
PascalCase effort file is an effort; a directory without one is a domain
namespace that groups work without being closable itself, and both participate
in slug chains.

`--verbose` additionally prints each effort's `gist` from its frontmatter.

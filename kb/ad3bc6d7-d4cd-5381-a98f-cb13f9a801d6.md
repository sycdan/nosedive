# List dives (deprecated)

Use `preflight` instead. Its backlog and free-dive surface is the supported way
to find work. This command remains available for compatibility with older
bridges.

`<effort>` accepts an effort path, effort directory path, or leaf-first slug
chain.

Dives are read from the effort's `links:` frontmatter -- the same durable link
list kb docs use. A link is a repo-root file path such as `kb/<id>.md` or a
`- kb/<id>.md: { rel, anchor }` object; only links resolving to `kind: dive`
docs are considered.

## Sections

- **Pickupable** -- linked dives with `rel: pending`.
- **Working** -- linked dives with `rel: working` or `rel: reviewing`, or any
  linked dive with `meta.diver` set.
- **Historical** -- linked dives with no pickup role, plus any dive whose
  `meta.effort` resolves to the effort. Shown only with
  `--include-historical`.

## Warnings

Broken dive links (missing from kb, or pointing at another effort) and held
dives that name the effort but are not linked from it are reported as
warnings.

`--json` prints the same sections as structured data for agent workflows.

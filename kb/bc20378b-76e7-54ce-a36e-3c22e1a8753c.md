# Add repo to effort

Resolves `<repo-id-or-name>` against bridge KB `kind: repo` docs by `id` or
exact `name`, then appends that repo id to the active `kind: effort` doc's
`scopes:` list.

The active effort is read from local `current.effort`, or from the active dive
marker when a dive is selected. `current.effort` may be an effort doc UUID,
bridge-root KB path such as `kb/<id>.md`, or exact effort `name`.

- `--ref` pins the effort scope to a ref. When omitted, the scope has no `ref`
  key and downstream scope resolution falls back to the repo's configured trunk.
- `--read-only` records the effort scope with `mode: ro`; otherwise the command
  records `mode: rw`.

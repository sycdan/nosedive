# Dump backlog

Renders the body of the bridge KB memo configured as `backlog:` in
`.nosedive/config.yaml`.

Use [`update-backlog`](eb6305b4-9aa6-5fdb-b622-e0d17b6303bb.md) to regenerate
that memo from bridge KB effort docs.

At L1, `backlog:` is the UUID of the memo that indexes current work. This
supersedes the L0 directory walker, which traversed the configured `backlog:`
directory directly.

# Pitch

Deprecated. The command records a `kind: feat` doc and is named
[record.feat](fb3d90e6-9dbf-5f1c-9919-6653d12fe085.md); this spelling routes to
the same implementation so nothing pinned to it breaks, and takes the same
positional gist and options.

At L1 a feat is a KB doc, not a `backlog/` directory. This supersedes the L0
pitch, which wrote `backlog/<slug>/<Pascal>.md`.

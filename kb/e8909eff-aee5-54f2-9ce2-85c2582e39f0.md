# Mint

Generates UUIDv7 values with a chosen timestamp encoded in the high bits, so
minted ids sort in the order they were meant to represent rather than the
order they happened to be created.

- `[count]` defaults to `1`, and must be an integer between 1 and 1000. Each
  additional id advances the encoded timestamp by one millisecond, so a batch
  sorts lexicographically.
- `--ms` takes Unix milliseconds and `--ts` takes an ISO 8601 date string. They
  are exclusive, and the start point defaults to now when neither is given.
- Every encoded timestamp, including the last one in a batch, must fall inside
  the 48-bit UUIDv7 range.

Example:

`npx -y nosedive@dev mint 3 --ts 1997-08-29T02:14:00-04:00`

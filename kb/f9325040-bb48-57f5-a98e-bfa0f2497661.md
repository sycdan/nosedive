# Pitch

The gist is the first positional argument, because it is the one thing a pitch
cannot be useful without. Everything else has a workable default.

`--name` is the effort's leaf slug in kebab-case. When it is omitted the effort
is named `new-effort-<yyyy>-<mm>-<dd>-<hhmmss>`, so an effort can be pitched
before it has a good name and renamed later.

`--parent` accepts an effort doc UUID, a bridge-root KB path such as
`kb/<id>.md`, or an exact effort `name`. The new effort's `name` is the
leaf-first slug chain `<slug>.<parent-chain>`, and parent and child link to each
other in `links:` with `rel: child` and `rel: parent`.

The new doc holds only frontmatter and a title heading. Framing belongs in the
effort's own body once there is something to frame.

Pitch fails when an effort with the same slug chain already exists.

At L1 an effort is a KB doc, not a `backlog/` directory. This supersedes the L0
pitch, which wrote `backlog/<slug>/<Pascal>.md`.
